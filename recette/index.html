Moteur graphique restreint (WebAssembly / CanvasKit)

AutoRoomzio n'a pas pu démarrer le moteur graphique CanvasKit. Dans les environnements d'entreprise, ceci survient généralement lorsque WebAssembly est bloqué par le Mode de Sécurité Renforcée de Microsoft Edge ou par une stratégie de groupe (GPO).

Actions recommandées :
  • Microsoft Edge : Rendez-vous sur edge://settings/privacy et configurez le « Mode de sécurité renforcée » pour ajouter cette URL en exception ou le désactiver temporairement pour ce site.
  • Navigateurs d'entreprise : Autorisez l'URL dans vos paramètres de confiance ou contactez votre support informatique si une GPO bloque WebAssembly.
